# .agents/ 目录导航

`.agents/` 是本项目的 Agent 协作层，存放接手上下文、硬约束、验证规则、任务状态和过程产物。

## 核心文件

| 文件 | 类型 | 用途 |
|------|------|------|
| `context.md` | 当前事实 | Agent 接手摘要：项目定位、目录结构、已支持站点、外部依赖 |
| `invariants.yaml` | 硬约束 | 架构分层边界、允许/禁止模式、本地操作要求、质量门命令 |
| `quality-gates.md` | 验证规则 | 按改动类型（Python / Extension / 文档 / 架构）的验证矩阵 |
| `task-board.yaml` | 任务状态 | 当前已完成、进行中、待办任务列表 |
| `task-template.md` | 模板 | 新建可追踪任务的格式模板 |

## 过程产物目录

| 目录 | 用途 | 默认行为 |
|------|------|----------|
| `specs/` | 设计规格与功能草案 | 不自动暂存/提交 |
| `plans/` | 实施计划 | 不自动暂存/提交 |
| `reviews/` | 审查报告 | 不自动暂存/提交 |
| `handoff/` | 会话交接文档 | 不自动暂存/提交 |

过程产物不是当前项目事实。实施完成后，持久性发现应迁入 `docs/`、合同、任务状态或代码。

## 使用规则

- **开发前**：从 `task-board.yaml` 领取或确认任务，对照 `invariants.yaml` 检查边界
- **验证后**：按 `quality-gates.md` 运行相关检查
- **完成后**：更新 `task-board.yaml` 任务状态
- **新会话**：按 `AGENTS.md` 指定的接手顺序读取本目录文件

## 与 docs/ 的边界

- `docs/` 存放**项目事实**：架构、接口、能力、实现细节
- `.agents/` 存放**协作状态**：约束、验证、任务、上下文

两者不互相复制。如果信息既是长期事实又是协作约束，在 `docs/` 维护事实，在 `.agents/` 只引用。
